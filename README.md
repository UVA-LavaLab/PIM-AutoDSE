## PIM-AutoDSE Simulator

![Contribution](https://img.shields.io/badge/Contribution-Welcome-blue) 
![License](https://img.shields.io/badge/license-MIT-green.svg)

This repository extends [PIMbench-PIMeval](https://github.com/UVA-LavaLab/PIMeval-PIMbench).  
It integrates **event-driven simulation** for execution time and energy across different PIM architectures, and supports **instruction fusion** for PIM.
